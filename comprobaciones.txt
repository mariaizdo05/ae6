5. AUTENTICACIÓN LDAP
---------------------

Comando:
docker exec dpl-cliente ldapwhoami -x \
-H ldap://172.20.0.2 \
-D "uid=alumno,ou=usuarios,dc=dpl,dc=local" \
-w TU_CONTRASEÑA

Salida:
dn:uid=alumno,ou=usuarios,dc=dpl,dc=local


Comando:
docker exec dpl-cliente ldapwhoami -x \
-H ldap://172.20.0.2 \
-D "uid=alumno,ou=usuarios,dc=dpl,dc=local" \
-w incorrecta

Salida:
ldap_bind: Invalid credentials (49)


6. LOGIN DE LA APLICACIÓN
-------------------------

Login correcto:

Comando:
docker exec dpl-cliente curl -i -X POST \
-d "usuario=alumno&password=TU_CONTRASEÑA" \
http://www.dpl.local/api/login

Resultado:
HTTP/1.1 200 OK


Login incorrecto:

Comando:
docker exec dpl-cliente curl -i -X POST \
-d "usuario=alumno&password=incorrecta" \
http://www.dpl.local/api/login

Resultado:
HTTP/1.1 401 Unauthorized
